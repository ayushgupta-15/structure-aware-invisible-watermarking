Structure-Aware Invisible Image Watermarking: An Investigation into Robustness Under Diffusion-Based Image Regeneration

Domain: Digital Image Processing  |  Sub-area: Digital Image Watermarking

Status note (read first). This report covers the complete implementation of the watermarking system and its evaluation on 20 DIV2K images against three conventional attacks. The diffusion-regeneration attack, the project's central question, is fully implemented but was not executed on the development machine (no GPU); see Section 12.3. No diffusion results are claimed in this report.

1. Abstract

Invisible image watermarks are known to be fragile to diffusion-based regeneration, and content-adaptive embedding is known to help against conventional attacks. We investigate whether structure-aware embedding changes watermark survival. We implemented a DWT-DCT-SVD watermarking scheme with quantization index modulation (QIM) on the singular-value gap, where the quantization step is scaled per block by either local pixel variance or Canny edge density, and compared it with uniform-strength embedding. On 20 DIV2K validation images (512×512 crops, 80-bit payload) all three variants are visually imperceptible (mean PSNR 53.45 dB, SSIM 0.9991) and recover the payload exactly with no attack. Under conventional attacks, edge-driven embedding had the lowest mean bit error rate under every conventional attack tested, with the paired gain over uniform embedding exceeding two standard errors for only some attacks (Table 2); robustness was weak overall for every variant (BER near 0.5 under strong JPEG and noise). A diffusion-regeneration attack (SDEdit-style, Stable Diffusion v1.5) is implemented and packaged for GPU execution; its results are pending.

2. Introduction

Digital image watermarking is the process of embedding auxiliary information into an image so that the information can later be recovered or detected, typically without being visible to a human observer. Invisible watermarks are widely used for copyright protection, ownership verification, and image authentication, because they do not alter the visual appearance of the image while still allowing a rights holder to prove ownership or verify authenticity later. With the wider availability of generative image models, invisible watermarking has also become relevant to tracing whether an image has been produced or modified by an AI system.

This report presents our current understanding of the problem, a review of literature published mostly between 2020 and 2026, and the plan of investigation for our B.Tech major project. The project has since been implemented and evaluated on conventional attacks (Sections 10-13); the diffusion-regeneration experiment is implemented but its status is stated explicitly in Section 12.3.

3. Background

3.1 Digital image watermarking

A digital image watermarking system generally has two parts: an embedding procedure, which inserts a payload (a bit sequence or an image) into a cover image with minimal visible distortion, and an extraction or detection procedure, which recovers the payload or determines whether a watermark is present. Embedding can be performed in the spatial domain (directly modifying pixel values) or in a transform domain (e.g., using the Discrete Wavelet Transform, Discrete Cosine Transform, or Singular Value Decomposition), or using a deep neural network trained to embed and extract a watermark.

3.2 Invisible watermarking and robustness

A watermark is called "invisible" if embedding it does not produce a perceptible change to the image, and "robust" if it can still be recovered after the image undergoes common transformations such as JPEG compression, resizing, cropping, noise addition, or filtering. Robustness is typically measured by comparing the recovered watermark to the original payload after such a transformation, using metrics such as Bit Error Rate (BER) or Normalized Correlation (NC).

3.3 Diffusion-based image regeneration

Diffusion models are a class of generative models that produce images by starting from random noise and progressively removing (denoising) that noise using a neural network trained on large image datasets, until a realistic image emerges. The same denoising mechanism can be applied to an existing image: noise is added to the image, and the diffusion model then removes that noise, effectively regenerating the image content. This process can be used for legitimate image editing, but it can also alter or remove information embedded in the image, including invisible watermarks, because the denoiser reconstructs plausible image content from its learned prior rather than reproducing the exact original pixel values.

4. Motivation

This problem is worth investigating for a B.Tech project for a few reasons. First, it sits within the department's stated research areas of signal processing, digital image processing, and digital image watermarking, and builds on concepts (transform-domain embedding, robustness evaluation) already studied in the department. In this sense, the project is aligned with the assigned faculty's general research interests in image processing and digital watermarking; we are not claiming that our specific proposed method is an extension of her published algorithm, since her work addresses reversible watermarking, a different design goal from the robustness question this project studies.

Second, the specific sub-question this project asks — whether adapting embedding to image structure changes robustness under diffusion-based regeneration specifically — appears to be only partially addressed in the literature we reviewed, most of which either (a) studies content-adaptive embedding only under conventional attacks, or (b) studies regeneration attacks only against uniform-strength embedding. Third, the experimental pipeline required (a watermark embedder, a pretrained diffusion model used only at inference time, and standard image-quality/watermark metrics) is realistic for a student team to build with existing open-source tools, without training any large generative model.

5. Problem Statement

ESTABLISHEDMultiple recent studies report that passing a watermarked image through a diffusion-based regeneration process can substantially reduce the detectability of invisible watermarks, including watermarks designed to be robust to conventional distortions (Zhao et al., 2023; An et al., 2024). This is a comparatively new threat model that was not the primary attack considered when many earlier watermarking methods were designed and evaluated.

The problem this project is concerned with is therefore: current invisible watermarking methods, including those designed to be robust to conventional image-processing operations, appear to be vulnerable to diffusion-based regeneration, and it is not clear from the literature we reviewed whether simple, structure-adaptive changes to the embedding process meaningfully change this outcome, help only in some cases, or make no difference.

6. Review of Relevant Work

We reviewed literature along four lines: (A) evidence that diffusion-based regeneration affects invisible watermarks, (B) benchmark/evaluation work on watermark robustness, (C) work explaining or exploiting how diffusion-based processes degrade watermark information, and (D) existing content-aware or saliency-aware watermarking methods. We also looked briefly at (E) the assigned faculty's published work, to understand how this project relates to the department's existing research.

6.1 Diffusion-based regeneration as an attack on invisible watermarks

Zhao et al. (2023), "Invisible Image Watermarks Are Provably Removable Using Generative AI." Formalises "regeneration attacks," in which a watermarked image is perturbed with noise and then reconstructed using a generative model (including diffusion-based models), and shows this can remove watermark information across several existing methods without knowledge of how the watermark was embedded. Relevant because it establishes the core threat this project is concerned with. It evaluates existing methods as they are, and does not study whether structure-adaptive embedding changes the outcome.

An et al. (2024), "WAVES: Benchmarking the Robustness of Image Watermarks" (ICML 2024). Proposes a standardised evaluation protocol combining conventional distortions with regeneration-style and adversarial attacks, and reports that several widely used watermarking methods (transform-domain and deep-learning-based) show reduced detectability under these attacks. Relevant as a template for structuring our own, much smaller-scale, evaluation. It is a benchmark of existing methods, not a study of adaptive embedding.

6.2 Explaining and exploiting the mechanism of degradation

"When Denoising Becomes Unsigning: Theoretical and Empirical Analysis of Watermark Fragility Under Diffusion-Based Image Editing" (preprint, 2026). Analyses, theoretically and empirically, why the denoising step in diffusion-based editing tends to remove watermark signals: the denoiser reconstructs images consistent with its training distribution, and a watermark perturbation is an out-of-distribution signal it has no reason to preserve. Gives a mechanistic explanation we can use to motivate the research question. Does not test structure-adaptive embedding.

"Saliency-Aware Diffusion Reconstruction for Effective Invisible Watermark Removal" (Companion Proceedings of the ACM Web Conference, 2025). Reports that guiding a diffusion-based reconstruction attack using saliency information can make watermark removal more effective, not less. An important cautionary reference: it shows that structure/saliency information is not automatically an advantage for the defender, and may in some circumstances assist an attacker instead. This directly shapes how conservatively we state our expected outcomes (Section 14).

6.3 Content-adaptive and saliency-adaptive watermarking (against conventional attacks)

Liu, Liu, and Zhao (2018), "Visual Saliency Model-Based Image Watermarking with Laplacian Distribution," and a related complex-wavelet visual-saliency watermarking study (2019). Adapt watermark embedding strength using a visual saliency model, reporting improved imperceptibility and robustness against JPEG compression, noise, filtering, and geometric attacks. Establishes that content-adaptive embedding is a known, reasonably effective idea for conventional attacks. Neither evaluates diffusion-based regeneration, which was not an existing attack model at the time.

Rakhmawati, Wirawan, Suwadi, Delpha, and Duhamel (2022), "Blind robust image watermarking based on adaptive embedding strength and distribution of quantified coefficients," Expert Systems with Applications. Adaptively selects embedding strength and coefficients to reduce distortion while maintaining robustness to geometric and conventional image-processing attacks. Same relevance and limitation as above: adaptive embedding is studied only under conventional attacks.

6.4 Baseline watermarking methods considered

DwtDctSvd (as implemented in the open-source invisible-watermark library). A transform-domain method combining Discrete Wavelet Transform, Discrete Cosine Transform, and Singular Value Decomposition; used as the reference watermarking implementation in Stability AI's Stable Diffusion release. We selected this as our baseline because it is practical, reproducible, and requires no training — not because it is claimed to be the best-performing watermarking method available.

Zhu et al. (2018), HiDDeN, and Tancik et al. (2020), StegaStamp. Deep-learning-based encoder-decoder watermarking systems trained end-to-end, reporting robustness improvements over classical methods against conventional distortions. Considered only as an optional second baseline if time allows, since pretrained checkpoints exist; heavier to set up than DwtDctSvd, so treated as a stretch goal, not a requirement.

6.5 Generation-time (not post-hoc) watermarking

Wen et al. (2023), Tree-Ring, and Yang et al. (2024), Gaussian Shading. Embed a watermark into the initial noise used by a diffusion model during image generation, reporting strong robustness to regeneration-style attacks by design. Relevant as context but not directly comparable: these require control over the generative model producing the image, whereas this project concerns watermarking an already-existing image, a post-hoc setting these methods do not address.

6.6 Assigned faculty's related work

Tanwar and Panda (2023/2024), "Hybrid reversible watermarking algorithm using histogram shifting and pairwise prediction error expansion." Addresses reversible watermarking, where both the watermark and the exact original image can be recovered — a different design goal from the robust, lossy watermarking studied here, which does not require exact recovery of the original image. Referenced only to connect this project to the department's general area of expertise in digital watermarking. We are not proposing to extend this specific algorithm.

7. Research Gap

ESTABLISHEDDiffusion-based regeneration can degrade or remove invisible watermarks, including methods designed to resist conventional attacks (Zhao et al., 2023; An et al., 2024). Content-adaptive/saliency-adaptive embedding is an established technique for improving robustness against conventional attacks such as JPEG compression, noise, and filtering (Liu et al., 2018-2019; Rakhmawati et al., 2022). Separately, at least one 2025 study shows saliency-guided processing can also make watermark removal more effective when used by an attacker.

TO BE VERIFIEDWhether adapting watermark embedding to image structure changes (improves, has no effect on, or worsens) watermark survival specifically under diffusion-based regeneration attacks has not been clearly established one way or the other in the papers we reviewed.

PROPOSED BY USWe propose to investigate this specific, narrow question experimentally, using a simple and reproducible structural cue (not deep semantic segmentation) layered onto an existing, well-established watermarking baseline.

We do not claim this is "the first" study of this question. We were unable to find a paper that directly studies it, but the absence of a matching paper in our search is not proof that no such work exists — only that our proposed investigation appears to address a narrow, specific gap in what we reviewed. If closely related work is identified later (for example, during a more exhaustive review at implementation time), we will acknowledge it explicitly and adjust the framing of our contribution accordingly.

8. Research Question

Primary research question: Does adapting invisible watermark embedding strength according to simple structural characteristics of an image (such as local texture/variance and edge density) change watermark detectability after diffusion-based image regeneration, compared to uniform-strength embedding, while maintaining acceptable visual quality?

One possibility explored in this project is that embedding strength based on image structure may affect watermark survival differently from uniform embedding under regeneration; whether this difference is an improvement, no meaningful change, or a disadvantage is precisely what the project intends to determine, not something assumed in advance.

9. Objectives

  1. Study existing invisible image watermarking methods and their robustness to image transformations, with particular attention to diffusion-based regeneration attacks.
  2. Implement a suitable baseline invisible watermarking method (DwtDctSvd).
  3. Develop a simple structure-aware modification that adjusts embedding strength according to selected image characteristics (local variance, edge density).
  4. Evaluate both approaches under conventional image-processing attacks and a selected diffusion-based regeneration condition.
  5. Compare image quality and watermark recovery performance using appropriate quantitative metrics, and analyse the conditions (if any) under which the structure-aware approach differs from the uniform baseline.

We have deliberately not included an objective requiring the design of a new deep-learning architecture; the project's core contribution is the comparison itself, not a new model.

10. Methodology and Implementation

10.1 Embedding algorithm

We implemented our own DWT-DCT-SVD embedder (svd_watermark.py) because the open-source invisible-watermark library uses one fixed strength for the whole image and cannot vary it per block. The pipeline is: (1) one-level Haar DWT of the blue channel; (2) split the LL subband into 8×8 blocks; (3) per block, 2-D DCT then SVD; (4) encode one payload bit by quantization index modulation on the gap d = σ1 − σ2 of the two largest singular values: with step Δ, q = round(d/Δ) is forced odd for bit 1 and even for bit 0, and σ1, σ2 are rescaled to the new gap while preserving their sum; (5) inverse SVD, inverse DCT, reassemble LL and inverse DWT. Extraction repeats the DWT/DCT/SVD and reads the parity of round(d/Δ). Extraction is non-blind with respect to the strength map (the map is recomputed from the host image, as in the experiments here).

One implementation issue worth recording: setting the two singular values from a QIM step can push σ2 below the third singular value, silently breaking the SVD ordering and corrupting that bit. We cap the achievable gap per block so the ordering is preserved. We also swept the base strength from 5 to 200: below about 40, ordinary 8-bit pixel quantization alone corrupts bits, so we use 50.

10.2 Structure maps

Two training-free maps are computed per 16×16 block of the full-resolution grayscale image (aligned one-to-one with the 8×8 LL blocks) and normalized to [0, 1]: local variance and Canny edge density. The per-block step is Δb = Δ0(1 + α·sb), with Δ0 = 50 and α = 1. Experiment 1 is uniform (sb = 0), Experiment 2 variance-driven, Experiment 3 edge-driven.

10.3 Attacks

  • JPEG recompression at quality 50 and 30.
  • Additive Gaussian noise with σ = 10 and 20 (pixel units).
  • Gaussian blur with kernel 5 and 7.
  • Diffusion regeneration (SDEdit-style): add partial noise to the watermarked image and denoise with Stable Diffusion v1.5 img2img, empty prompt, 30 steps, regeneration strength 0.2, 0.4 and 0.6 (phase4_diffusion_attack.py).

11. Experimental Setup

  • Data: the first 20 images of the DIV2K validation set, resized (shorter side to 512) and center-cropped to 512×512.
  • Payload: the 10-character string "DTU-ECE-25", i.e. 80 bits. A 512×512 image offers 1024 blocks, so the payload is embedded in the first 80.
  • Metrics: PSNR and SSIM (imperceptibility, and attack severity); bit error rate (BER; 0 = perfect, 0.5 = chance) and normalized correlation (NC; 1 = perfect, 0 = uncorrelated) of the recovered bits.
  • Tooling: Python, NumPy, OpenCV, scikit-image, PyWavelets; run_experiments.py reproduces every number below, writing results/conventional_results.csv.

12. Results

12.1 Imperceptibility and attack-free recovery

Averaged over all images and variants, the embedded images have PSNR 53.45 dB and SSIM 0.9991 against the originals. With no attack, all three variants recover the payload exactly (BER 0, NC 1) on every image.

12.3 Diffusion-regeneration attack: status

Not executed in this report. The attack and evaluation code are written (phase4_diffusion_attack.py, run_experiments.py --diffusion) but have not been run, and a Colab notebook (colab_diffusion.ipynb) runs it on a free T4 GPU. The development machine has no GPU and 7 GB of RAM, which is insufficient for Stable Diffusion v1.5 over a dataset. Accordingly, this report makes no claim about whether structure-aware embedding helps or hurts under diffusion regeneration; that remains the open question. Based on the literature cited in Section 6, we expect all three variants to degrade strongly, since DWT-DCT-SVD watermarks are reported to be removed by regeneration; this expectation is not a result.

13. Analysis and Discussion

  • Edge-driven embedding had the lowest mean BER in every attack in these runs. Table 2 shows the gain is statistically clear (beyond 2 s.e.m.) only for some attacks, marked with *. Standard deviations across images are large, so with 20 images these are indications, not strong evidence.
  • Robustness is weak in absolute terms. At JPEG q30 and noise every variant is near chance (BER ≈ 0.5). The scheme embeds in a single LL-band singular-value gap with one bit per block and no error-correcting code, so any attack that flips a modest share of blocks corrupts the payload. This is a limitation of the base scheme, not of the structure maps.
  • Single-image results did not generalize. On our earlier single test image, variance-driven embedding performed best under JPEG. On 20 DIV2K images the edge-driven variant is best instead. This shows why a single image is not an adequate basis for conclusions and why the multi-image evaluation matters.
  • Relation to the research question. Conventional attacks are blind mechanical distortions; diffusion regeneration is a semantic re-synthesis. A benefit seen against JPEG does not imply a benefit against regeneration, and a related 2025 study suggests saliency information can even help an attacker. The diffusion experiment is therefore required to answer the question, and it is pending.

14. Limitations

  • The central diffusion experiment was not run (Section 12.3).
  • Only 20 images, one payload, one base strength and one α were evaluated; no confidence intervals beyond standard errors and no multiple-comparison correction.
  • No error-correcting code and no repetition coding; one bit per 8×8 LL block, with extraction that recomputes the structure map from the host image.
  • Only the blue channel is used; no geometric attacks (crop, rotation, scaling) were tested.
  • The strength map is derived from the original image; after an attack it would be recomputed from a modified image in a fully blind setting, which we did not evaluate.

15. Future Work

  • Run the diffusion experiment on Colab (notebook provided) on 10-50 images and report BER with confidence intervals.
  • Add error-correcting coding and redundancy, then re-evaluate robustness.
  • Evaluate blind extraction (structure map recomputed from the attacked image) and additional attacks (crop, rotation, VAE regeneration, WAVES benchmark attacks).
  • Compare against deep-learning watermarks (e.g., Tree-Ring, Gaussian Shading) under the same attack.

16. Conclusion

We built an end-to-end structure-aware DWT-DCT-SVD watermarking pipeline, verified it is imperceptible and exactly recoverable without attack, and evaluated uniform, variance-driven and edge-driven embedding on 20 DIV2K images under JPEG, noise and blur. Edge-driven embedding gave the lowest BER in these tests, but all variants are fragile at stronger attacks. The diffusion-regeneration experiment that the research question depends on is implemented and ready for GPU execution but not yet run, so the question remains open; we report this plainly rather than extrapolate.
